# Support

## How to file issues and get help

This project uses [GitHub Issues](https://github.com/microsoft/LinuxBrokerForAVDAccess/issues) to track bugs and feature requests. Please search the existing issues before filing new issues to avoid duplicates.

For new issues, file your bug or feature request as a new Issue. Include relevant details such as deployment configuration, error messages, and steps to reproduce.

For security vulnerabilities, please see [SECURITY.md](SECURITY.md) for responsible disclosure instructions. **Do not report security issues through GitHub Issues.**

## Microsoft Support Policy

This is a Microsoft open-source project. Support is limited to GitHub Issues and the resources available in this repository.
